## Layer-Flow v1.11.3

- **Custom Element HUD Controller:** Pixel-perfect positioning (D-Pad), scaling (50% to 200%), and per-element padding for all 9 music/player elements.
- **Synced Lyrics & Podcast Captions:** Full LRC / SRT / WebVTT / YouTube transcript parsing, YouTube video ID caption fetching, and custom transcript editor.
- **Top Toolbar Visibility:** Toggle in Settings -> Appearance to keep the top pill handle visible or completely hidden off-screen.
- **Deep Sleep Mode (Zero RAM/CPU):** Toggle Layer into sleep mode via `Ctrl+Shift+H` or Moon toolbar button to free all active memory and CPU for gaming or heavy apps.
- **Customizable Quit Shortcut:** Dedicated `Ctrl+Shift+Q` hotkey and toolbar power button to terminate Layer completely.
- **Performance & Background Leak Audits:** Halted 60 FPS visualizer animation loops when paused and eliminated redundant wallpaper and clipboard polling.
